# Test Maker — سامانه آزمون‌ساز آنلاین

نسخه بهبود‌یافته Test Maker با حفظ ساختار اصلی React + Vite + Express + Supabase.

## امکانات این نسخه

- ورود و ثبت‌نام و نقش‌های ادمین اصلی، طراح و کاربر
- ساخت آزمون با سه نوع سؤال تک‌پاسخی، چندپاسخی و درست/نادرست و اعتبارسنجی پاسخ‌ها
- وزن اختصاصی برای هر سؤال و محاسبه نمره بر اساس مجموع وزن‌ها؛ در سؤال چندپاسخی باید تمام پاسخ‌های صحیح و فقط همان‌ها انتخاب شوند تا امتیاز کامل سؤال ثبت شود
- توضیح اختیاری پاسخ صحیح که در کارنامه نمایش داده می‌شود
- ویرایش آزمون تا پیش از ثبت اولین شرکت‌کننده
- آرشیو آزمون به‌جای حذف؛ کارنامه‌های قبلی حفظ می‌شوند
- ذخیره خودکار پاسخ‌های نیمه‌تمام روی همان دستگاه
- نمایش میزان پیشرفت پاسخ‌گویی و هشدار سؤالات بی‌پاسخ
- شاخص‌های خلاصه عملکرد، جست‌وجوی آزمون‌ها، تحلیل درصد پاسخ صحیح هر سؤال و خروجی CSV نتایج
- طراحی واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- قابلیت نصب به شکل PWA روی Android و iOS
- کش پوسته برنامه برای باز شدن رابط کاربری در حالت آفلاین؛ ثبت و دریافت اطلاعات همچنان به اینترنت نیاز دارد

## ۱. تنظیمات Supabase

در SQL Editor پروژه Supabase، کل محتوای فایل `schema.sql` را اجرا کنید.

این فایل هم ساخت اولیه دیتابیس را انجام می‌دهد و هم ستون آرشیو و رابطه حفظ کارنامه‌ها را به دیتابیس نسخه قبلی اضافه می‌کند. اجرای دوباره آن برای جدول‌ها و ایندکس‌های موجود طراحی شده است.

## ۲. فایل محیطی

نام متغیرها و تنظیمات ENV تغییر نکرده‌اند. همان فایل `.env` قبلی را در ریشه پروژه نگه دارید:

```env
SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
SUPABASE_KEY=YOUR_SUPABASE_KEY
```

هیچ متغیر محیطی جدیدی لازم نیست.

## ۳. اجرای محلی در Windows / PowerShell

```powershell
npm install
npm run dev
```

فرانت‌اند: `http://localhost:5173`

بک‌اند: `http://localhost:3001`

## ۴. ساخت نسخه Production

```powershell
npm run build
```

## ۵. نصب روی موبایل

### Android

1. سایت را با Chrome و از طریق آدرس HTTPS باز کنید.
2. گزینه «نصب اپلیکیشن» را داخل برنامه بزنید؛ یا از منوی Chrome گزینه Install app / Add to Home screen را انتخاب کنید.
3. آیکون Test Maker به صفحه اصلی اضافه می‌شود و برنامه در حالت مستقل اجرا خواهد شد.

### iPhone / iPad

1. آدرس HTTPS سایت را در Safari باز کنید.
2. دکمه Share را بزنید.
3. گزینه Add to Home Screen یا «افزودن به صفحه اصلی» را انتخاب کنید.

> برای نصب PWA در سرور واقعی، سایت باید از HTTPS ارائه شود. Vercel به‌صورت پیش‌فرض HTTPS فراهم می‌کند. باز شدن رابط کاربری از کش در حالت آفلاین ممکن است، اما ورود، دریافت آزمون و ثبت پاسخ‌ها به اتصال اینترنت و API نیاز دارد.

## ۶. انتشار روی Vercel

پروژه را مانند نسخه قبلی به GitHub متصل و روی Vercel Deploy کنید. متغیرهای `SUPABASE_URL` و `SUPABASE_KEY` فعلی را بدون تغییر نگه دارید. فایل‌های `public/manifest.webmanifest`، `public/sw.js` و آیکون‌ها به‌صورت خودکار همراه Build منتشر می‌شوند.

## نکته مهم درباره آرشیو و ویرایش

- دکمه آرشیو، آزمون را از فهرست فعال کنار می‌گذارد اما رکورد آزمون و نتایج آن را حذف نمی‌کند.
- برای جلوگیری از تغییر معنای کارنامه‌های قبلی، آزمونی که حداقل یک شرکت‌کننده دارد قابل ویرایش نیست. برای ایجاد تغییرات، آزمون جدید بسازید.
- وزن هر سؤال به‌صورت پیش‌فرض ۱ است. نمره هر آزمون با نسبت مجموع وزن سؤالات صحیح به مجموع وزن همه سؤالات محاسبه می‌شود.
